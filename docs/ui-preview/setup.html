Willkommen

Der Proxy hält die einzige Verbindung zum Wechselrichter und verteilt die Werte: als SunSpec-Wechselrichter an Consolinno, an Home Assistant, KNX oder andere Modbus-Programme. Welche Dienste laufen, wählst du gleich aus.

  • Display zeigt die Proxy-IP (Ethernet bevorzugt), falls das Board eines hat
  • Alles lässt sich später unter Einstellungen ändern

Was soll das Gerät tun?

Abgewählte Dienste starten nicht und erscheinen nicht im Menü. Unter Einstellungen, Funktionen lassen sie sich jederzeit einschalten.

Consolinno anbinden

In der Consolinno-App „Fronius Hybrid (SunSpec)“ oder „SunSpec Generic“ wählen. IP = diese Proxy-Adresse, Port = 1502 (SunSpec). Automatischer Scan auf 502 findet den Proxy nur, wenn SunSpec dort lauscht — Standard hier ist 1502.

…
  • SunSpec-Port am Proxy: 1502
  • Unit / Slave = 1

Den HIT nicht zusätzlich direkt in Consolinno eintragen. Modbus-Gateway (:502) dann auslassen oder auf einen anderen Port legen.
